# 테스트 안정성 — 비결정적 SIGSEGV 조사

**상태:** 조사 중 (2026-08-18 시작)
**대상:** `godot --headless --path . -s res://addons/gut/gut_cmdln.gd`
**영향:** CI(`.github/workflows/quality.yml`)가 같은 명령을 돌린다. 무작위로 빨개지면 테스트가 안전망이 아니다.

이 문서는 **조사하면서 쓴다.** 결론이 나기 전에도 관측한 것은 그때그때 적는다.
레인은 언제든 끊길 수 있고, 그때 남는 것은 디스크에 쓴 것뿐이다.

---

## 1. 증상

통합자가 관측한 것 (조사 착수 시점의 입력):

- 5회 중 2회가량 신호 11(SIGSEGV)로 죽는다. 나머지는 811/811 전부 통과한다
- **죽는 자리가 매번 다르다.** 관측된 위치:
  - `src/core/npc/person_seed.gd:57` — `rng.seed = stream(...)`
  - `src/ui/base/base_screen.gd:65` — `_ready()` → `NpcWorld.create` → `_build_population`
  - `src/core/char_anim/front_idle_clip.gd:74` — `pose.positions[part] += Vector2(...)`
  - `src/core/dungeon/dungeon_blueprint.gd`
- 죽는 자리는 **전부 평범한 GDScript 산술/대입**이다. 그 코드 자체에 잘못이 보이지 않는다
- **단정(assert) 실패는 한 건도 없다.** 통과할 때는 전부 통과한다

### 배제된 것 — GPU/VRAM

이 저장소는 과거 VRAM 고갈로 무관한 프로세스들이 `0xc0000005` 로 죽은 전례가 있다
(`CLAUDE.md` 「GPU 를 나눠 쓴다」). 그래서 먼저 확인했다.

관측 시점 VRAM 848 MiB / 16376 MiB, ComfyUI 미기동. **이번 건은 VRAM 이 아니다.**

## 2. 조사 방법

### 원칙 — 추측하기 전에 잰다

「~일 것 같다」로 처방을 고르지 않는다. 재현률과 죽는 자리의 분포를 먼저 숫자로 만든다.

### 반복 실행 러너

`tools/repeat_gut.py` — 빌드에 들어가지 않는 조사 도구.
GUT 를 N 회 돌려 회차별 종료 코드 · 통과 수 · 크래시 위치를 표로 만든다.

*(작성 중 — 사용법은 확정되는 대로 여기 적는다)*

### GUT 인자 주의

`-gtest=` 인자가 **조용히 무시되는 것을 이미 확인했다.** 한 파일만 돌렸다고 믿지 말고
출력에 실제로 몇 개 스크립트가 돌았는지 확인할 것.
