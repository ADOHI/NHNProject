## 9.1.1 이 게임은 아트 부담이 낮다

기획 구조상 **그림으로 전달해야 하는 것이 거의 없다.**

| 요소 | 표현 수단 | 아트 필요량 |
| --- | --- | --- |
| 던전 공간 | 방 노드 + 연결선 + 숫자 ([`07`](07-level-design.md) §7.1) | 도형·UI |
| 다른 방의 사건 | **렉카 기사 텍스트** ([`08`](08-ui-ux.md) §8.3) | **없음** |
| NPC 탐험가 | 이름 + 초상 1장 | 캐릭터당 1장 |
| 전투 | 결과 표시 (연출 아님) | 거의 없음 |
| 몬스터 | 아이콘 · 숫자 | 아이콘 |

**애니메이션·스프라이트 시트·타일맵이 전부 불필요하다.**
1인 90시간([`01-constraints.md`](01-constraints.md) §1.3)에서 아트가 코드를 멈추지 않는다는 뜻이고,
웹 초기 로딩 문제도 거의 사라진다.

**대신 UI·타이포그래피가 곧 아트다.** 플레이어가 보는 시간의 대부분이
숫자판과 텍스트 피드이므로, 여기서 인상이 결정된다.

## 9.2 비주얼 스타일

**미정.** 방향 후보:

- **SNS / 방송 UI 를 그대로 차용** — 렉카 피드가 실제 SNS 타임라인처럼 보인다.
  톤([`02`](02-overview.md) §2.5)과 직결되고, 도형·폰트만으로 완성된다. 아트 비용 최소.
- 보드게임 판 — 방 노드를 물리적 말·카드처럼.
- 지도 · 문서 — 탐험가의 수기 지도처럼.

## 9.3 폰트 · 가독성

이 게임에서 **폰트가 스프라이트보다 중요하다.**

| 항목 | 값 |
| --- | --- |
| 한글 폰트 | 미정 — **웹 용량 주의.** 한글 폰트는 크다. 서브셋 필요 |
| 위험도 숫자 | 미정 — 판 위에서 즉시 읽혀야 한다 |
| 기사 본문 | 미정 — 긴 텍스트를 읽는 화면이므로 가독성 우선 |

**한글 폰트 파일이 이 게임 최대의 용량 항목이 될 수 있다.** §9.1 예산에 반영한다.
