## 9.1.1 이 게임은 아트 부담이 낮다

기획 구조상 **그림으로 전달해야 하는 것이 거의 없다.**

| 요소 | 표현 수단 | 아트 필요량 |
| --- | --- | --- |
| 던전 공간 | 방 노드 + 연결선 + 숫자 ([`07`](07-level-design.md) §7.1) | 도형·UI |
| 다른 방의 사건 | **렉카 기사 텍스트** ([`08`](08-ui-ux.md) §8.3) | **없음** |
| NPC 탐험가 | 이름 + 초상 1장 | 캐릭터당 1장 |
| 전투 | 결과 표시 (연출 아님) | 거의 없음 |
| 몬스터 | 아이콘 · 숫자 | 아이콘 |

**애니메이션·스프라이트 시트·타일맵이 전부 불필요하다.**
1인 90시간([`01-constraints.md`](01-constraints.md) §1.3)에서 아트가 코드를 멈추지 않는다는 뜻이고,
웹 초기 로딩 문제도 거의 사라진다.

**대신 UI·타이포그래피가 곧 아트다.** 플레이어가 보는 시간의 대부분이
숫자판과 텍스트 피드이므로, 여기서 인상이 결정된다.

## 9.3 폰트 · 가독성

이 게임에서 **폰트가 스프라이트보다 중요하다.**

| 항목 | 값 |
| --- | --- |
| 한글 폰트 | **임시 조치 중 — §9.3.1** |
| 위험도 숫자 | 미정 — 판 위에서 즉시 읽혀야 한다 |
| 기사 본문 | 미정 — 긴 텍스트를 읽는 화면이므로 가독성 우선 |

**한글 폰트 파일이 이 게임 최대의 용량 항목이 될 수 있다.** §9.1 예산에 반영한다.

### 9.3.1 한글 폰트 — SongMyung 임베드 (확정)

Godot 기본 폰트에는 **한글 글리프가 없다.** 그대로 두면 UI 가 전부 두부(□)로 나온다.

| 항목 | 값 |
| --- | --- |
| 폰트 | **SongMyung Regular** (명조) |
| 위치 | `assets/fonts/song_myung/SongMyung-Regular.ttf` |
| 라이선스 | SIL Open Font License 1.1 — `OFL.txt` 동봉 (재배포 조건) |
| 용량 | **2.03 MB** |
| 적용 | `project.godot` 의 `gui/theme/custom_font` |

**임베드 폰트라 웹에서도 동작한다.** 이전의 `SystemFont` 임시 조치는
데스크톱에서만 동작해 제출물이 깨졌을 것이다.

### 9.3.2 서브셋은 지금 하지 않는다

2.03 MB 를 줄이려면 쓰는 글자만 추출하면 되지만, **지금은 위험하다.**

렉카 기사 문장은 마감 직전까지 늘어난다
([`16`](16-build-order.md) §16.6 — 자투리 시간에 채우는 항목).
서브셋을 미리 고정하면 나중에 넣은 글자가 두부로 나오고,
그 시점엔 발견하기도 어렵다.

**판단 시점: UI 문구와 기사 템플릿이 확정된 뒤.**
그때도 전체 웹 빌드 용량 대비 2 MB 의 비중을 보고 결정한다
(Godot 웹 빌드는 wasm 만으로 이미 수십 MB 다).

### 9.3.3 남은 확인

**웹 빌드에서 실제로 임베드되는지는 CI 결과로 확인해야 한다.**
데스크톱 렌더링 확인은 마쳤다.
