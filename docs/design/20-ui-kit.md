# 20. UI 키트 — 나전(螺鈿)

> **상태: 3차 시도, 진행 중.** 이 문서는 UI **원자 단위**(버튼 · 팝업)의 조형 언어를 정한다.
> 구현은 `src/ui/kit/`, 에셋은 `assets/ui/kit/`, 확인용 화면은 `src/ui/kit/kit_showcase.tscn`.

이 문서는 **매 단계 갱신된다.** 심사를 받을 때마다 §8 에 결과를 적는다.
레인은 언제든 끊기고, 그때 남는 것은 디스크에 쓴 것뿐이다.

---

## 20.1 앞의 두 번이 왜 실패했는가 — 원인은 브리핑에 있었다

1·2차 시도는 **등고선 · 파편 · 알갱이** 세 방향을 만들었고 셋 다 불합격이었다.
평가 원문:

> "코드로만 짜야하니까 쉐이프나 쉐이더로 노이즈 넣고 이렇게만 짜네.
> 아니 그게 아니라 아름다워야 하고 스타일리시 해야 한다고.
> 레이어드 한 UI도 고려해보고 애니메이팅도 고려해보고. **이건 무슨 수학 같음.**"

**원인은 조형 감각이 아니라 제약 조건이었다.** 모든 UI 브리핑에 "에셋 추가 금지,
코드로 만들어라" 가 들어 있었다. 그러면 남는 표현 수단이 **도형과 셰이더 노이즈**뿐이고,
그 둘로 만들 수 있는 것은 필연적으로 **절차적 무늬** — 즉 「수학」이다.
재료가 없으니 재료의 아름다움이 나올 자리가 없었다.

그 금지의 근거였던 「웹 빌드 용량」은 [`01`](01-constraints.md) §1.2 에서 **실측으로 반증됐다.**

| 파일 | 크기 |
| --- | --- |
| `index.wasm` — Godot 엔진 | 37.7 MB |
| `index.pck` — 우리 게임 전부 | 1.5 MB |

**전체의 96%가 엔진이다.** 그러므로 이번 판은 **에셋을 쓴다.**

### 두 번째 원인 — 아직 없는 게임에 UI 를 재단했다

> "UI를 너무 아직 나오지도 않은 게임에 맞춰 재단하려고 한 거야.
> 그냥 팝업, 버튼 이런 것들에 좀 더 포커스 맞추고."

그래서 이번에 만드는 것은 **버튼 하나와 팝업 하나뿐**이다.
게임 화면 · 전투 HUD · 게이트 목록을 만들지 않는다.

### 세 번째 원인 — 「컨셉」을 서사로 이해했다

> "이 컨셉이라는 게 어떤 뉴스 뭐 이런 거에 맞추라는 게 아니라
> **그림체, 규격, 간격, 애니메이션, 쉐이더, 효과** 이런 것에 포커스 맞추라는 거야."

**컨셉 = 조형 언어**다. 소재(렉카 · 게이트 · 던전)를 UI 에 그려 넣는 일이 아니다.
이 문서가 정하는 것은 정확히 저 여섯 가지다.

## 20.2 컨셉 — 한 문장

> **UI 는 그려진 그림이 아니라 **박아 넣은 물건**이다.
> 검은 옻칠 판을 파내고, 그 자리에 **자개 조각**을 손으로 잘라 박는다.
> 화면이 살아 있는 이유는 시간 uniform 이 돌아서가 아니라,
> **자개가 보는 각도에 따라 색이 변하는 재료이기 때문**이다.**

「나전칠기(螺鈿漆器)」의 조형만 가져온다. 전통 공예 이야기를 하지 않는다.
가져오는 것은 **재료의 물리**뿐이다.

### 왜 이 재료인가 — 세 가지가 한꺼번에 풀린다

| 요구 | 이 재료가 답이 되는 이유 |
| --- | --- |
| **아름다워야 한다** | 새까만 바탕 + 차가운 편광 + 금선 하나. 대비가 극단이고 색이 셋뿐이라 실패하기 어려운 배색이다 |
| **레이어드** | 나전은 태생이 겹이다. 옻칠 바닥 / 파낸 홈 / 박힌 조각 / 그 위에 다시 올린 투명 옻 / 광택. **겹이 개념이 아니라 물건의 사실** |
| **idle 애니메이션** | **자개는 가만히 있어도 색이 변한다.** 움직임을 지어낼 필요가 없다. 재료의 성질을 그대로 재생하면 그게 idle 이다 |

### 그리고 이것이 「수학」의 반대인 이유

**셰이더가 색을 만들지 않는다.** 색은 실제 자개 사진이 가지고 있고,
셰이더는 그 색을 **어느 위상에서 읽을지만 정한다.**
노이즈 함수로 무늬를 합성하는 것과 정반대의 방향이다.

> **원칙: 셰이더는 재료를 만들지 않는다. 재료를 움직일 뿐이다.**

## 20.3 조형 여섯 가지

### 20.3.1 그림체

| 항목 | 값 |
| --- | --- |
| 바탕 | **면이 있다.** 검은 옻칠. `#0B0A09` ~ `#141210` |
| 잉크 | 없음. **선으로 그린 것이 하나도 없다** |
| 유일한 선 | **황동 실선** 1px, `#E3B36A`. 그리고 **닫히지 않는다** |
| 조각 | **직선 절단.** 손으로 자른 각진 조각. 둥근 모서리 금지 |
| 편광 | 민트 `#9FE6D2` · 시안 `#7FD4F0` · 라일락 `#C0AEE8` · 은 `#E8EEF0` |
| 드문 색 | 금 `#E3B36A` — 편광 램프의 끝자락에서만 나온다 |

**색은 셋뿐이다: 검정 · 자개 · 황동.** 네 번째 색을 쓰지 않는다.
자개 안에서 색이 여러 개로 보이는 것은 **하나의 재료가 각도에 따라 달리 보이는 것**이지
여러 색을 쓴 것이 아니다. 이 구분이 무너지면 화면이 무지개가 되고, 무지개는 싸구려다.

**둥근 모서리를 쓰지 않는다.** 자개는 실톱과 줄로 자르는 재료다. 곡선은 나오지만
**부드러운 라운드 코너는 나오지 않는다.** 모서리는 각지거나, 비스듬히 잘렸거나, 깨져 있다.

### 20.3.2 규격 — 원자는 자개 조각의 최소 폭

**끊음질**(자개를 실처럼 가늘게 끊어 붙이는 기법)의 조각 폭에서 치수를 유도한다.

- 길이의 원자 `U = 4px`
- 자개 이음매의 폭 `SEAM = 2U = 8px` — 판의 **왼쪽 모서리를 따라 세로로** 박힌다
- 화면에 보이는 조각 하나의 폭 `15px` — **판이 커져도 조각은 커지지 않는다**

조각 크기를 고정하는 것이 중요하다. 실제 나전에서 조각 크기는 판 크기와 무관하고,
띠를 통째로 늘이면 큰 버튼에서 조각이 굵어져 상감이 아니라 무늬 타일이 된다.
그래서 이음매는 늘이는 것이 아니라 **원판에서 더 긴 구간을 잘라 온다**
(`uv_offset` / `uv_scale`).

| 급 | 높이 | 글자 | 좌우 여백 |
| --- | --- | --- | --- |
| 보조 | 9U = **36px** | 13 | 6U = 24px |
| 주 행동 | 11U = **44px** | 15 | 7U = 28px |
| 결단 | 14U = **56px** | 18 | 9U = 36px |
| 팝업 제목 | — | 28 | — |

높이 비는 1.22 / 1.27 로 거의 같다. 폭은 글자가 정하되 **4px 의 정수배로 올림**한다.

**자간이 위계의 절반을 진다.** 폰트가 SongMyung(명조) 하나뿐이라 굵기 대비가 없다.
대신 **작은 글자일수록 자간을 넓게** 준다 — 명조는 자간을 벌리면 격이 올라간다.

| 크기 | 자간 |
| --- | --- |
| 13 | +2.2px |
| 15 | +2.0px |
| 18 | +1.6px |
| 28 | +0.8px |

### 20.3.3 간격 — **무엇이 이어지는가**로 읽힌다

여백 수치는 눈에 보이지 않는다. 보이는 것은 **이음매의 박자가 끊겼는가**다.
이음매가 판마다 왼쪽 모서리에 서 있으므로, 판을 붙이면 이음매가 일정한 간격으로
반복되는 **한 줄의 상감**이 되고, 떼면 그 박자가 깨진다.

| 급 | 값 | 화면에서 보이는 것 |
| --- | --- | --- |
| **한 몸** | 1U = 4px | 이음매가 판 폭만큼의 박자로 **끊기지 않고 되풀이된다.** 한 줄의 상감으로 보인다 |
| **한 묶음** | 4U = 16px | 박자가 한 번 흐트러진다. 그래도 **황동 실선의 높이가 같아** 한 묶음으로 남는다 |
| **남남** | 10U = 40px | 박자도 선의 높이도 이어지지 않는다 |

"두 행동이 한 몸이되 같은 것은 아니다" 를 `4px` / `16px` 이라는 숫자는 절대 말하지 못한다.
**박자가 이어지는가 아닌가**는 말한다.

### 20.3.4 레이어 — 버튼 하나가 겹 일곱 장이다

**이것이 이 키트의 핵심이다.** 겹마다 다른 속도로 움직이고, 그 속도 차이가 깊이가 된다.
평면 하나에 셰이더를 먹이는 것과 근본적으로 다르다.

| # | 겹 | 재료 | 움직임 |
| --- | --- | --- | --- |
| 0 | **잔광** | 자개색 번짐 | 판 아래로 새어 나온다. 호버에서 벌어진다 |
| 1 | **옻칠 바닥** | 흑칠 사진 | 기준. 움직이지 않는다 |
| 2 | **속반사** | 같은 사진, 다른 배율 | 바닥의 **1.6배 속도**로 미끄러진다 → 옻의 두께가 보인다 |
| 3 | **자개 이음매** | 나전 사진 | 왼쪽 모서리에 세로로. **조각마다 편광 위상이 다르다** |
| 4 | **흩어진 조각** | 잘라낸 조각 3~5개 | **틀 밖으로 넘어간다.** 개별 표류 |
| 5 | **황동 실선** | 단색 | 모서리를 지나쳐 뻗는다 |
| 6 | **글자** | SongMyung | 눌림에서만 1px 내려간다 |
| 7 | **유광 시트** | 광택 그라디언트 | **가장 빠르다.** 판 위를 지나간다 |

겹 2 와 겹 7 이 서로 반대 방향으로 흐르면, 정지 화면에서도 **판에 두께가 있다**고 읽힌다.

### 20.3.5 애니메이션 — idle 과 포커스

**리빌 · 하이드가 아니다.** 가만히 있을 때와 커서가 올라갔을 때 계속 살아 있는 것이다.
그리고 **시간 uniform 만 도는 게 아니라 요소 자체가 움직인다.**

**idle (아무도 안 건드릴 때)**

| 무엇 | 어떻게 |
| --- | --- |
| **편광이 돈다** | 자개 조각마다 위상이 다르다. 한 조각이 시안일 때 옆 조각은 라일락이다 |
| **조각이 표류한다** | 흩어진 조각 3~5개가 실제로 위치를 바꾼다. ±1.5px, 12~20초 주기, 위상 전부 다름 |
| **속반사가 미끄러진다** | 겹 2. 초당 3px 안팎. 눈에 「보이는」 것이 아니라 판이 죽지 않게 한다 |
| **유광이 아주 느리게 지나간다** | 겹 7. 40초에 한 번 판을 훑는다 |

**호버**

| 무엇 | 어떻게 |
| --- | --- |
| **이음매에 불이 차례로 켜진다** | 빛 한 줄이 이음매를 훑는다. 조각이 애초에 낱개로 끊겨 있어 **stagger 를 코드로 짤 필요가 없다** |
| **황동 실선이 자란다** | 모서리 밖으로 12px 뻗어 나간다 |
| **판이 떠오른다** | 2px 위로. 잔광(겹 0)이 벌어진다 |
| **속반사가 빨라진다** | 초당 3px → 11px |

**눌림**

| 무엇 | 어떻게 |
| --- | --- |
| **조각이 튄다** | 자개 조각 2~3개가 실제로 8px 밀려 나갔다 되돌아온다 |
| **유광이 꺼진다** | 겹 7 이 즉시 사라진다. 광택은 각도의 함수인데 판이 눌렸다 |
| **판이 내려앉는다** | 2px 아래. 잔광이 오므라든다 |

**포커스**

| 무엇 | 어떻게 |
| --- | --- |
| **황동이 판 둘레를 돈다** | 닫힌 링이 아니라 **밝은 한 마디가 궤도를 도는 것**. `ring-offset` 과 구별되는 지점 |
| **편광 파동** | 이음매 전체를 밝기 파동이 계속 지나간다 |

**비활성**

편광이 죽는다. 자개가 그냥 **회백색 조개껍질**이 된다 (채도 0, 명도 유지).
옻칠은 무광이 되고 유광 시트가 없다. **아무것도 움직이지 않는다.**
흐리게 칠한 버튼이 아니라 **재료가 죽은 것**이다.

**상태 전이 시간** — 붙는 것이 떨어지는 것보다 빠르다.

| | 붙음 | 떨어짐 |
| --- | --- | --- |
| 호버 | 0.09s | 0.24s |
| 눌림 | 0.04s | 0.18s |
| 포커스 | 0.16s | 0.16s |

### 20.3.6 셰이더 — 재료를 움직일 뿐이다

`gl_compatibility`(WebGL2) 이므로 컴퓨트 셰이더가 없다. 전부 `canvas_item` 프래그먼트.

| 셰이더 | 하는 일 | 하지 않는 일 |
| --- | --- | --- |
| `kit_nacre.gdshader` | 자개 사진의 **휘도를 간섭 램프의 좌표로** 쓴다. 위상을 옮기면 색이 바뀐다 | 노이즈로 색을 합성하지 않는다 |
| `kit_lacquer.gdshader` | 같은 흑칠 사진을 두 배율로 겹쳐 속반사를 만든다 | 그라디언트를 그리지 않는다 |
| `kit_gloss.gdshader` | 각도의 함수인 광택 한 장 | 블룸 · 글로우를 쓰지 않는다 |

**배격 목록**

| 하지 않는다 | 왜 |
| --- | --- |
| 절차적 노이즈로 무늬 합성 | 앞의 두 판이 여기서 죽었다. 「수학」이 된다 |
| 주사선 · 격자 · 비네트 · 색수차 | 장르 기성품. 겹쳐도 필터다 |
| 페이드 · 슬라이드 · scale pop | 엔진 기본값이지 애니메이션이 아니다 |
| 올리면 밝아지는 반응 | 웹 버튼이다 |
| 둥근 모서리 | 자개는 톱으로 자른다 |
| 무지개 편광 | 채도를 풀면 즉시 싸구려가 된다. 차가운 쪽 좁은 대역만 |
| 네 번째 색 | 검정 · 자개 · 황동 셋으로 끝낸다 |

## 20.4 팝업 — 덮지 않고 **판을 갈아 끼운다**

화면을 어둡게 덮는 반투명 판을 쓰지 않는다 (그건 어느 웹앱에나 있다).

**팝업은 더 큰 옻칠 판이 앞으로 나오는 것**이다. 뒤에 있던 것은
어두워지는 것이 아니라 **초점이 나가고 편광이 멎는다** — 뒤판의 자개는 각도를 잃어
회색이 되고, 앞판의 자개만 살아 움직인다. **깊이가 밝기가 아니라 재료로 읽힌다.**

- 팝업 테두리에는 자개 띠가 **세 변**에만 박힌다 (네 변을 두르면 액자가 된다)
- 자개 조각 몇 개가 **팝업 밖으로 넘어가** 뒤판 위에 떨어져 있다
- 안에 놓인 버튼은 같은 언어를 그대로 쓴다. 층을 따로 관리하지 않는다

## 20.5 에셋 — 무엇을 생성하고 왜 그것이어야 하는가

`assets/ui/kit/` 에 둔다. 전부 **검정 바탕에 생성**한다 —
바탕이 검정이면 알파 채널 없이 **가산 합성(ADD)** 만으로 깨끗하게 얹힌다.
매트 추출이 필요 없고, 그것이 이 컨셉이 에셋 파이프라인과 맞아떨어지는 지점이다.

| 파일 | 무엇 | 왜 코드로 못 만드나 |
| --- | --- | --- |
| `nacre_sheet.webp` | 자개 원판 매크로 | 진주층의 층간 간섭 무늬는 절차적으로 흉내가 안 된다 |
| `lacquer_ground.webp` | 흑칠 바닥 | 옻의 깊이는 노이즈가 아니라 사진이다 |
| `inlay_band.webp` | 손으로 자른 조각을 이어 붙인 띠 | **조각 폭의 불규칙**이 손맛이다. 난수로 만들면 난수처럼 보인다 |
| `shards.webp` | 흩어진 조각 낱개 | 겹 4 의 재료 |

생성 모델은 **Klein 4B Pro**(`fluxKlein4BPro_v10.safetensors`), 4스텝.
프롬프트는 **평서문 · 60단어 이내**로 쓴다 — Klein 은 길어지면 지시를 통째로 흘린다(실측).

## 20.8 심사 기록

작업을 **아주 작은 단위로 쪼개** 단계마다 독립 심사자 둘에게 받는다.
한 사람에게 **"아름다운가"** 와 **"독창적인가"** 를 따로 묻는다 —
앞 판본은 독창성만 좇다가 아름다움을 잃었다.
**"괜찮다" 는 실패다.** 무엇이 왜 부족한지 나와야 한다.

### 0차 — 심사에 내보내기 전 스스로 고친 것

심사자를 부르기 전에 여섯 번 렌더해서 여섯 번 고쳤다. 이 기록을 남기는 이유는,
**같은 실수를 팝업에서 되풀이하지 않기 위해서**다.

| 렌더 | 무엇이 틀렸나 | 고친 것 |
| --- | --- | --- |
| r1 | **판에 실루엣이 없었다.** 옻칠과 바탕의 값이 거의 같아 버튼이 안 보임 | 판을 올리고 바탕을 내려 다섯 배 가까이 벌림 |
| r1 | 자개 띠가 판 **밑에 깔린 다른 물건**으로 보임 | 아래로 옻칠을 남겨 판 안에 박음 |
| r1 | 1024px 원판을 10px 로 짓눌러 조각이 **뭉개진 얼룩**이 됨 | 늘이지 않고 **잘라 오도록** 바꿈 (`uv_offset`/`uv_scale`) |
| r1 | 조각 둘이 겹쳐 **나비 모양 얼룩** | 거리를 위상이 아니라 `slot` 이 정하게 함 (가까운 것 하나, 먼 것 하나) |
| r2 | 띠가 판 아래를 가로질러 **진행 막대**로 읽힘 | 오른쪽으로 갈수록 흩어져 사라지게 함 (`dissolve_from`) |
| r3 | 판이 **회색 플라스틱**으로 보임 | 광택을 선형에서 거듭제곱으로 바꿔 위쪽에 몰고, 바탕값을 낮춤 |
| r4 | 조각이 **잿빛 종잇조각** | 사진 색을 거의 버리고 간섭색에 맡김 (`material_mix` 0.95) |
| r4 | 띠가 여전히 글자 밑의 **자막 판** | 상감을 **왼쪽 모서리를 따라 세로로** 세움. 글자와 다투지 않고, 나전에서 상감은 원래 모서리를 따라 간다 |
| r5 | 광택이 판을 가로지르는 **흰 얼룩** | 좁고 날카로운 정반사 한 줄로 바꿈 (폭 0.30 → 0.10, 지수 2.2 → 3.4) |
| r5 | 호버에서 이음매가 하얗게 **타 버림** | 훑는 빛의 세기 1.60 → 0.85 |
