# 03. 코어 루프

> **상태: 미정.** [`02-overview.md`](02-overview.md) 의 핵심 재미를 시간 축으로 펼친 것이다.

---

## 3.1 초 단위 루프

**미정.** — 매 순간 반복되는 입력·판단·결과. (예: 조준 → 발사 → 회피)

## 3.2 판 단위 루프

**미정.** — 한 판 안에서 반복되는 단위. (예: 진입 → 전투 → 보상 → 다음 방)

## 3.3 판 사이 루프

**미정.** — 한 판이 끝나고 다시 시작할 때 무엇이 남는가.
남는 것이 없으면 "다시 하기"의 동기가 무엇인지 여기에 적는다.

## 3.4 다시 하게 만드는 것

**미정.** — 실패했을 때 플레이어가 "내 탓"이라고 느끼게 하는 장치.
