# 15. 세계 갱신 — 살아 있는 판

> **상태: 구조 확정 / 구현 방식 제안.**
> **던전을 한 판 진행할 때마다 세계의 모든 NPC 가 갱신된다.**

---

## 15.1 원칙

**세계는 플레이어를 기다리지 않는다.**

플레이어가 던전을 한 번 다녀오는 동안, 다른 탐험가들도 각자의 던전을 다녀온다.
누군가는 부자가 되고, 누군가는 유명해지고, **누군가는 죽는다.**

| 갱신되는 것 | 내용 |
| --- | --- |
| 생사 | NPC 가 죽는다. **영구히** |
| 재산 · 장비 | 잘 벌면 강해진다 |
| 주목도 | 화제의 인물이 바뀐다 ([`13`](13-information-design.md) §13.4) |
| 스쿼드 구성 | NPC 스쿼드도 영입하고 잃는다 ([`14`](14-squad.md)) |
| 관계도 | NPC 끼리도 관계가 생긴다? → §15.6 |
| 위치 · 소속 | 다른 던전으로 옮겨 간다 |

---

## 15.2 왜 이것이 강력한가

### 15.2.1 렉카 기사가 아웃게임에서도 산다

던전 안에서만 쓰던 기사 시스템([`08`](08-ui-ux.md) §8.3)이
**주둔지 화면의 뉴스 피드**로 그대로 재사용된다.

> 📰 이번 주 대박 났다는 그 스쿼드 ㅋㅋ 결국 전멸했답니다<br>
> 📰 "칼날의 요한" 드디어 은퇴각? 요즘 조용하네요<br>
> 📰 신인 뜬다 — 3연속 무사귀환한 애 누구냐

**생성기 하나를 두 화면에서 쓴다.** 90시간에서 이보다 좋은 재사용은 없다.

### 15.2.2 NPC 가 인물이 된다

기사에서 이름을 반복해 보고, 던전에서 실제로 마주치고,
관계를 쌓고, 결국 영입한다 — 그때 그 이름에 무게가 붙는다.

**서사를 작성하지 않고 서사가 생긴다.** 스토리·컷신을 만들 시간이 없는
프로젝트([`10`](10-content-scope.md) §10.3)에서 이건 결정적이다.

### 15.2.3 결정에 시한이 생긴다

- 영입하려던 대원이 **죽어 있다**
- 노리던 탐험가가 다른 던전으로 **옮겨 갔다**
- 만만하던 스쿼드가 어느새 **강해져 있다**

**"나중에 하지"가 통하지 않는다.** 아웃게임에 시간 압박이 생기고,
이건 인게임의 주목도 압박([`13`](13-information-design.md) §13.2)과 같은 결의 긴장이다.

## 15.3 구현 — 실제로 시뮬레이션하지 않는다

**NPC 의 던전 플레이를 진짜로 돌리면 안 된다.** 비용이 감당되지 않고,
웹 단일 스레드([`01`](01-constraints.md) §1.2)에서 프레임이 멈춘다.

### 결과만 굴린다

각 NPC 에 대해 **주사위 몇 번**으로 결과를 정하고, 그 결과에서 기사를 만든다.

```
NPC 마다:
  능력 · 스쿼드 규모 · 도전한 던전 난이도
        ↓  (확률 판정)
  성공 / 부분 성공 / 실패 / 사망
        ↓
  재산 · 주목도 · 생사 갱신
        ↓
  기사 생성 (기존 생성기 재사용)
```

**필요한 데이터는 NPC 당 정수 몇 개다.** 위치·전투·경로 같은 건 존재하지 않는다.
NPC 30명이어도 판당 계산은 순식간에 끝난다.

### 이 방식의 정직함

플레이어는 결과와 기사만 본다. 내부적으로 정교한 시뮬레이션이 돌든
주사위를 굴리든 **구분할 수 없다.** 구분할 수 없는 곳에 비용을 쓰지 않는다.

## 15.4 세계 인구

**미정.**

| 항목 | 값 | 고려 |
| --- | --- | --- |
| 전체 NPC 탐험가 수 | 미정 | 너무 적으면 세계가 좁고, 너무 많으면 아무도 기억 못 한다 |
| 한 던전당 등장 수 | 미정 | [`05`](05-rules.md) §5.2.2 |
| 신규 유입 | 미정 | 죽어 나가면 보충되어야 세계가 마르지 않는다 |

**기억되는 것이 목적이므로 수보다 반복 노출이 중요하다.**
30명이 있어도 매번 다른 사람을 만나면 아무도 기억에 남지 않는다.
**주목도 높은 소수가 자주 등장**하는 편이 낫다 — 그리고 그건 이미 규칙으로 있다.

---

## 15.5 주의 — 세계가 플레이어를 앞질러 가면 안 된다

**가장 큰 위험이다.** NPC 들이 알아서 성장하는데 플레이어만 뒤처지면,
플레이어는 **자기 게임의 주인공이 아니게 된다.**

| 안전장치 | 내용 |
| --- | --- |
| NPC 성장 상한 | 미정 — 무한히 강해지지 않는다 |
| NPC 도 죽는다 | 잘나가던 스쿼드가 전멸하는 사건이 주기적으로 필요 |
| 플레이어 기준 보정 | 미정 — NPC 성장률을 플레이어 진행도에 맞춘다 |

**"잘나가던 놈이 죽었다"는 기사가 정기적으로 떠야 한다.**
그게 세계가 살아 있다는 증거이면서, 동시에 플레이어의 심리적 안전장치다.

→ [`12-open-questions.md`](12-open-questions.md) Q28

## 15.6 미정

| 항목 | 내용 |
| --- | --- |
| NPC 끼리의 관계 | NPC 들도 서로 협력·배신하는가. 넣으면 세계가 깊어지지만 비용이 붙는다 |
| 플레이어가 안 간 던전의 처리 | 그 던전의 귀중품은 NPC 가 털어 가는가 (= 안 가면 손해) |
| 갱신 주기 | 던전 1회 = 1틱 확정. 그 외 시간 흐름이 있는가 |
| 세계 상태의 가시화 | 순위표 · 인물 목록 · 뉴스 피드 중 무엇을 보여 주는가 |

**"플레이어가 안 간 던전의 자원이 줄어든다"는 규칙은 강력하지만 위험하다.**
모든 던전을 다 돌 수 없으므로 항상 손해 보는 기분이 든다.
넣는다면 손해가 아니라 **선택의 대가**로 느껴져야 한다.
