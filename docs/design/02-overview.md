## 2.0 제목 — 「금」 (확정)

한 글자다. 그리고 **두 뜻이 겹친다.**

| 읽는 법 | 뜻 | 게임에서 |
| --- | --- | --- |
| 금(金) | 황금 | 던전에 들어가는 이유 |
| 금 | 균열 | *벽에 금이 가다* · **사이에 금이 가다** |

> **금을 캐러 들어가서, 사이에 금이 간 채로 나온다.**

**이 게임의 두 축이 한 글자에 들어간다** — 무엇을 챙겼는가, 그리고 누구와 틀어졌는가.
전자는 §2.1 의 목표이고 후자는 [`05-rules.md`](05-rules.md) §5.10 의 관계도다.

### 2.0.1 왜 이것으로 정했는가

후보를 네 갈래로 돌렸다. 폐기한 것과 이유를 남긴다 —
같은 논의를 반복하지 않기 위해서다.

| 폐기안 | 이유 |
| --- | --- |
| 「어그로」 | 게임 안 도발과 커뮤 어그로가 겹치는 것은 맞으나 **은어라 아는 사람만 안다** |
| 「지하 실황」 | 제목이 아니라 **분류명으로 읽힌다.** 장르 딱지처럼 보인다 |
| 「구경거리」 · 「다들 보고 있다」 | 뜻은 정확한데 **설명문이지 제목이 아니다** |
| 「동아줄」 | 잡은 줄이 썩었을 수 있다는 관계 은유는 좋으나 **전래동화 말투**다. 현대 커뮤 문체의 이 게임과 어긋난다 |
| 「Frayed」 | 영어권에는 흔한 말이지만 **한국 관객에게는 낯설다.** 제목의 이중 의미는 관객이 알아야 작동한다 |

**관객이 한국인이면 한국어가 이긴다.** 그것이 최종 판단 기준이었다.

### 2.0.2 알려진 약점

**검색으로는 찾을 수 없다.** 「금」은 한국어에서 가장 흔한 명사 중 하나라
금값·금시세가 결과를 다 가져간다.

**그런데 합성어로 만들면 뜻이 하나로 확정된다** — `금줄`은 금기의 줄로, `금가루`는 황금으로,
`금이 간다`는 균열로 읽힌다. **검색어를 얻으면 말장난을 잃는다. 둘 다는 안 된다.**

제출작 단계에서는 심사자가 검색해서 찾는 것이 아니라 제출본을 받아서 본다.
그 자리에서 두 뜻을 알아채면 제목이 할 일을 다 한 것이므로, **말장난을 지키기로 했다.**

필요해지면 로마자를 병기한다 — `금 GEUM`. 로고는 여전히 한 글자다.

### 2.0.3 타이틀 화면

컨셉은 **「금 간 금」**이다. 구도는 세 겹이고, 각 겹이 이 게임의 한 축이다.

| 겹 | 무엇 | 무엇을 말하는가 |
| --- | --- | --- |
| 가운데 | 금 간 금 | 노리는 대상이자 이미 갈라진 것 |
| 중경 | 사방에서 **차근차근 노리며** 다가오는 자들 | 다른 탐험대. 경쟁이자 협상 상대 |
| 원경 | **눈 하나 달린 렉카 악마들**이 웃으며 중계 | 이 판이 방송이라는 사실 |

**시선의 사슬이 핵심이다.** 캐릭터는 금을 보고, 악마는 캐릭터를 보고, 플레이어는 전부를 본다.
달려드는 것이 아니라 **재고 있는** 정지된 긴장이어야 한다 — 이 게임은 턴제다.

상세는 [`21-title.md`](21-title.md).

## 2.1 한 줄 컨셉

> 던전에 들어가 귀중품을 챙기고 **살아서 나오는** 턴제 게임.
> 가장 큰 위협은 몬스터가 아니라 **같은 목적으로 들어온 다른 탐험가들**이다.

## 2.2 장르

**턴제 던전 익스트랙션 (Extraction).**

두 장르의 결합이고, 각각에서 가져오는 것이 다르다.

| 장르 | 가져오는 것 |
| --- | --- |
| 익스트랙션 | 죽으면 잃는다 · 탈출해야 소유가 확정된다 · 다른 플레이어가 위협이자 전리품 |
| 턴제 | 조급함 없이 **계산할 시간**을 준다 · 웹/1인 개발에 유리 (실시간 물리·네트워크 동기화 없음) |

**턴제를 고른 것은 단순한 취향이 아니라 결합의 핵심이다.**
실시간 익스트랙션의 긴장은 반사신경에서 오지만, 이 게임의 긴장은
**정보가 부족한 상태에서 내리는 결정**에서 온다.
계획 페이즈([`03-core-loop.md`](03-core-loop.md))가 그 긴장을 담는 그릇이다.

## 2.3 핵심 재미 — 불완전한 정보 속에서 결정한다

**확정.** 플레이어가 매 턴 반복하는 행동은 하나다: **읽고, 추리하고, 건다.**

이 게임의 모든 시스템은 "정보"라는 한 축 위에 있다.

| 축 | 플레이어가 하는 것 | 담당 시스템 |
| --- | --- | --- |
| A. 언제 나갈까 | 위험도 숫자를 보고 더 갈지 물러설지 | 위험도 추리 ([`07`](07-level-design.md) §7.2) |
| B. 저 사람을 어떻게 대할까 | 기사와 성향을 읽고 죽일지·협상할지 | 렉카 피드 ([`08`](08-ui-ux.md) §8.3) · 성향 ([`05`](05-rules.md) §5.4) |

**A 와 B 를 둘 다 간다.** 통상 이 결정은 개발량을 두 배로 만들지만,
이 게임에서는 **두 축이 같은 재료를 쓴다.**

- A 의 도구는 **숫자**(정확·모호), B 의 도구는 **기사**(구체적·불신).
- 둘 다 **텍스트와 정수**다. 애니메이션·전투 연출·타일맵이 필요 없다.
- NPC 가 위험도 숫자에 포함되면 ([`07`](07-level-design.md) §7.2.5) **두 축이 한 화면에서 합쳐진다.**
  "3이던 방이 7이 됐다" 는 A 의 정보이면서 동시에 B 의 정보다.

**즉 이 게임은 전투 게임이 아니라 정보 게임이다.**
전투는 정보 판단이 틀렸을 때 치르는 대가일 뿐, 그 자체가 콘텐츠가 아니다.
이 관점이 90시간 안에서 A·B 를 동시에 성립시키는 근거다.
→ 범위 판단은 [`10-content-scope.md`](10-content-scope.md) §10.0.1

## 2.4 플레이 단위

| 항목 | 값 |
| --- | --- |
| 1회 플레이 시간 | 미정 (던전 1회 잠입 = 1세션으로 상정) |
| 세션 구조 | **아웃게임 ↔ 인게임 반복.** 던전 잠입을 반복하며 주둔지가 누적 성장 |
| 승리 조건 | 던전에서 **탈출**한다. 가지고 나온 것만 소유가 확정된다 |
| 패배 조건 | 던전에서 **사망**한다. 가진 것 대부분을 잃는다 |

**"승리"는 최종 목표가 아니라 매 판의 정산이다.**
게임 전체의 종료 조건(최종 목표)은 미정 → §2.7

## 2.5 타깃 · 톤

**톤 확정: 목숨 건 사투이면서, 남들에겐 구경거리.**

던전 잠입은 플레이어에겐 생사가 걸린 일이지만,
바깥에서는 **악동 스트리머가 SNS 렉카 채널로 중계하는 오락거리**다.
플레이어는 그 중계를 읽으며 정보를 얻는다 — 즉 **자신을 구경하는 시선을 이용해 살아남는다.**

이 톤이 게임에 주는 것:

- 진지한 다크판타지의 무게 없이 **가볍게 진입**할 수 있다 (웹 제출물에 유리)
- 실패가 조롱당하는 구조라 **다시 하고 싶어진다**
- 텍스트가 분위기 장식이 아니라 **기능**이 된다

**타깃: 미정.**

## 2.6.1 세계관 — 게이트물 (확정)

> **2026-08-08 전면 교체.** 이전 설정("던전은 방송용으로 지어진 시설")은 폐기됐다.
> 폐기본은 아래 §2.6.2 에 근거와 함께 남긴다.

**현대 게이트물이다. 그리고 게이트를 여는 것은 인간이 아니다.**

> **다른 차원의 존재들이 유희를 위해 게이트를 연다.**
> **인간은 거기서 건져 올 것이 있으니 목숨을 걸고 들어간다.**

| 요소 | 무엇 |
| --- | --- |
| **그놈들** | 다른 차원의 존재. **재미로 게이트를 열고, 안을 들여다보며 중계한다** |
| **게이트** | 그놈들이 연 문. 등급과 위치를 가진 아웃게임 대상 |
| **던전** | 게이트 안쪽 공간. 방 그래프. **게이트와 던전은 다른 것이다** |
| **길드** | 헌터 조직. 서로 경쟁하고 **영입 전쟁**을 벌인다 |
| **플레이어** | **길드 마스터이면서 동시에 플레이어블 캐릭터 한 명** |
| **렉카** | **그놈들 중 하나다.** 인간 언론이 아니다 |

### 2.6.1.1 이 설정의 핵심 — 양쪽 다 자발적이다

**아무도 억지로 들어가지 않는다.** 인간은 이익 때문에 들어가고, 그놈들은 재미 때문에 연다.
**그래서 더 잔인하다.** 피해자가 없고, 거래만 있다.

이것이 이 게임의 톤을 정한다. 비극이 아니라 **구경거리**다.
[`02-overview.md`](02-overview.md) §2.0 의 제목 「금」 — 금을 캐러 제 발로 들어간다.

### 2.6.1.2 이 설정이 설명하는 것

**이전 설정("인간이 방송용으로 시설을 지었다")보다 강하다.**
무리한 전제가 사라지고, 대신 **게이트가 왜 열리는지**가 처음으로 설명된다.
그건 이전에 빈칸이었다.

| 규칙 | 설명 |
| --- | --- |
| **조우는 방에서만 일어난다** | **그놈들이 그렇게 판을 짰다.** 통로에서는 그림이 안 나온다 |
| **왜 턴으로 끊기나** | 그놈들의 진행 단위다. 판을 한 호흡씩 끊어 본다 |
| **강제 이벤트** (가스 · 셔터 · 붕괴) | **개입이다.** 판이 지루해지면 손을 댄다 |
| **렉카 기사가 새어 나오는 이유** | 중계자가 그놈들 중 하나다. 새어 나오는 게 아니라 **틀어 주는 것**이다 |
| **주목도** | 그놈들의 관심. 눈에 띄면 판이 더 험해진다 |
| 방 단위 구획 | 구경하기 좋게 나뉘어 있다 |

**마지막 두 줄이 특히 크다.** 주목도가 단순한 수치가 아니라 **그놈들이 나를 지켜보는 정도**가 되고,
[`13-information-design.md`](13-information-design.md) §13.4 의 순환이 서사와 맞물린다.
그리고 앞으로 어떤 개입을 넣어도 정당화된다.

### 2.6.1.3 이 설정에서만 나오는 것들

**이중 역할이 아웃게임과 인게임의 분리를 정당화한다.**
아지트에서는 마스터로 판단하고, 게이트 안에서는 한 명으로 뛴다.
[`08-ui-ux.md`](08-ui-ux.md) §8.1 의 화면 흐름이 그대로 서사가 된다.

**길드 간 영입 전쟁이 관계도에 목적을 준다.**
[`05-rules.md`](05-rules.md) §5.10 의 친밀도가 단순한 호감이 아니라 **영입 경쟁의 자원**이 된다.

**타이틀 화면이 설정의 요약이 된다** (§2.0.3).
가운데 금, 사방에서 노리는 인간들, 원경에서 웃으며 보는 **눈 하나 달린 그놈들**.
**시선의 사슬이 곧 세계관이다.**

### 2.6.1.4 아직 안 정한 것

- 그놈들을 뭐라고 부르는가 (인간들이 붙인 이름이 있을 것이다)
- 인간이 그놈들의 존재를 얼마나 아는가 — 다 아는가, 소문 수준인가
- 그놈들이 인간 앞에 모습을 드러내는가

## 2.6.2 폐기된 설정 — 방송용 시설 (기록)

> **폐기 2026-08-08.** 게이트물로 교체됨. 왜 폐기했는지와 무엇을 잃었는지를 남긴다.
> **아래는 더 이상 유효하지 않다.**

**폐기 사유:** 렉카 하나를 정당화하려고 "던전을 방송용으로 지었다" 는 큰 전제를 깔았다.
게이트물에서는 같은 것이 전제 없이 성립한다. **설정이 규칙보다 무거우면 설정이 진다.**

이하 원문.

**턴제 게임의 규칙은 설명되지 않으면 "게임이니까"로 남는다.**
그래도 굴러가지만, 몰입은 거기서 끊긴다. 이 게임은 특히 설명이 필요한 규칙이 많다.

| 설득해야 할 규칙 | 플레이어의 의문 |
| --- | --- |
| 조우는 **방에서만** 일어난다 | 통로에서 마주치면 왜 아무 일도 없나 |
| 왜 **턴**으로 끊기나 | |
| 왜 정보가 **렉카 기사**로 들어오나 | 왜 남이 내 상황을 중계하나 |
| (도입 시) 왜 갑자기 가스가 터지나 | |

### 확정 — 던전은 방송용으로 만들어진 시설이다

**이미 렉카가 중계하고 있다.** 중계가 있다는 건 관중이 있고, 관중이 있다는 건
이게 **산업**이라는 뜻이다. 그렇다면 던전은 자연 동굴이 아니라
**탐험가가 들어가서 죽는 걸 구경하는 콘텐츠 시설**이다.

이 설정 하나가 위 규칙을 전부 설명한다.

| 규칙 | 설명 |
| --- | --- |
| 방 단위 구획 | 세트가 방으로 나뉘어 있다. 카메라가 방마다 있다 |
| 조우는 방에서만 | **통로는 중계 구역이 아니다.** 그림이 안 나오는 곳에선 아무 일도 안 일어난다 |
| 턴 | 방송 진행 단위 |
| 렉카 기사 | 애초에 중계되는 판이다. 새어 나오는 게 자연스럽다 |
| 주목도 | 화제성이 곧 카메라의 관심 |
| **강제 이벤트 (가스 · 셔터 · 조명)** | **연출이다.** 판이 지루해지면 개입한다 |

**마지막 줄이 특히 크다.** 이 설정을 깔아 두면 앞으로 어떤 강제 이벤트를 넣어도
정당화된다. 지금 정하지 않아도 되는 여지를 미리 확보하는 셈이다.

### 대안

| 안 | 내용 | 평가 |
| --- | --- | --- |
| 초자연적 제약 | "던전의 규칙" — 방 밖에서는 서로를 인지할 수 없다 | 싸고 무난. 대신 톤이 평범해진다 |
| 설명하지 않음 | 보드게임처럼 규칙으로 받아들이게 둔다 | 턴제 유저는 익숙하다. 다만 렉카 톤이 붕 뜬다 |

**방송 시설 안이 [`08`](08-ui-ux.md) §8.3 의 렉카 피드에서 공짜로 따라 나온다.**
이미 채택한 시스템에서 세계관이 도출되므로 추가 비용이 없다.

### 이 세계관이 이후 설계에 주는 것

| 시스템 | 세계관적 근거 |
| --- | --- |
| 스쿼드 ([`14`](14-squad.md)) | 방송에 출연하는 **팀**. 팀 단위가 콘텐츠의 기본 |
| 영입 ([`14`](14-squad.md) §14.5) | 유명 선수 이적. 주목도가 곧 몸값 |

| 아웃게임 뉴스 피드 | 방송 밖에서도 판은 화젯거리다 |

## 2.7 게임 전체의 목표

**미정.** 잠입을 반복하는 것 외에, 플레이어가 향하는 종착점이 있는가.

- 후보 1: 없음 — 하이스코어 / 얼마나 많이 벌었나
- 후보 2: 최종 던전 클리어 — 주둔지를 키워 마지막 던전 공략
- 후보 3: 목표 금액 달성 — "빚 갚기" 류의 명시적 목표
