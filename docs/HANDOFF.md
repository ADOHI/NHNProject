# 인계 — 인물 관계 레인

**맡는 것:** 인물 3000명의 관계도 · 사건 · 조우 (`src/core/npc/`, 브랜치 `npc-relations`).

**먼저 읽을 것**
1. `docs/design/24-npc-relations.md` §24.26 ~ §24.35 — 만든 것 · 실측표 · 함정. **여기에 다 있다**
2. 같은 문서 §24.14 미정표 — 열린 물음이 전부 여기 모여 있다
3. `docs/conventions.md` §5 (검사) · §5.1 (글리프)

**열린 물음**
- ★ 후유증 크기 `SHOCK`(12) — 사용자가 정한다. 레인 의견은 **12 유지**, 근거는 §24.14
- 남은 사건 15종 — 다음 묶음은 정보 계열(거짓 정보·정보 판매·밀고·시체 털이·길드 이탈)
- 유명세 변동 — 물음은 *"무엇이 사람을 도드라지게 하나"* (§24.32.3 이 잰 것)
- 세계 호감이 아직 단조 감소 — 원인은 사건 비율이 아니라 **±100 자르기의 비대칭** (§24.31.4)
- 동료 유기가 너무 드물다 (500건에 7건) — 다음 묶음에서 되맞춘다

**다음 할 일:** 정보 계열 다섯을 붙이고 §24.34.3 표를 다시 채운다. **끝을 먼저 재라** — 조금씩 밀면 못 찾는다.

**함정**
- **`--import` 0에러는 아무것도 보장하지 않는다.** 컴파일 실패는 GUT 의 **Scripts 수**가, 배치 붕괴는 **캡처**가 잡는다 (§24.35.1)
- **손잡이 값이 결과와 같아 보이면 안 된다.** 중간 층을 하나 끼운다 — 소속·성향이 그 일을 했다 (§24.29.3 · §24.30.6 · §24.33.2)
