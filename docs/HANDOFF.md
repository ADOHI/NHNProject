# 전투 레인 인수인계

**맡는 것:** 백팩 격자 + 체인 해석기 + 대련장 (`src/core/combat/` · `src/ui/backpack/`).

**먼저 읽어라:**
1. `docs/design/28-combat.md` §28.1~§28.10 — 사용자 구술. **확정된 것**
2. 같은 문서 §28.20.54 — **도구 · 검증 · 함정 · 손잡이 기본값** (여기부터 보면 빠르다)
3. 같은 문서 §28.20.39 — **재는 자를 의심한 자리들.** 같은 함정에 또 걸리지 마라

**열린 물음** (★ = 사람 답이 필요하다):
- ★ **여섯이 줄 서서 오는 것과 스무 명이 몰려오는 것 중 무엇이 이 게임인가** (§28.20.53)
- ★ 체이닝 조건 · 걸침 인원 · 표적 고르기 · 승리 조건 · 전진 뒤 남나 (§28.8 · §28.20.34/37/43)
- ★ 조장 중심 (§28.8.1 보류) · 자세 쌍을 누가 고르나 (§28.20.45 — 후보 하나는 수로 탈락)
- 앞 켜 거리를 누가 정하나 — §28.4 자동 이동에 걸린다 (§28.20.53)

**다음 할 일:** 적이 줄을 메우는 것(§28.20.53)이 §28.4 이동과 만나는 자리를 이동 레인과 맞춰라.

**함정 둘:**
- **전투 상한 6 은 「한 번에 닿는 수」지 던전에 있는 수가 아니다.** 적이 다가오면 사라진다 — **0 과 0 아닌 것 사이에서 갈리는 계단**이라 중간을 밀면 헤맨다 (§28.20.52 · §28.20.53)
- **`--import` 0 에러가 정상을 뜻하지 않는다.** 화면은 `tools/check_backpack_screen.gd` 로 따로 돌려라. 캡처만 GPU 를 쓴다 (§28.20.24 · §28.20.51)
