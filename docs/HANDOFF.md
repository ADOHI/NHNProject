# 전투 레인 인수인계

**맡는 것:** 백팩 격자 + 체인 해석기 + 대련장 (`src/core/combat/` · `src/ui/backpack/`).

**먼저 읽어라:**
1. `docs/design/28-combat.md` §28.1~§28.10 — 사용자 구술. **확정된 것**
2. 같은 문서 **§28.20.55 ~ §28.20.60** — 지금 판이 전부 여기 있다.
   줄이 메워짐 · 나이 띠 16~58 · 시간 상한 없음 · 무엇이 결과를 가르나 ·
   **대기 키와 기준판 정정** · 이동 레인에 준 답.
   **§28.20.59 를 안 읽고 §28.20.58 을 읽으면 인공물을 사실로 읽는다**
3. 같은 문서 §28.20.54 — 도구 · 검증 여섯 줄 · 손잡이 기본값
4. 같은 문서 §28.20.39 — **재는 자를 의심한 자리들.** 같은 함정에 또 걸리지 마라

**지금 제일 큰 것 — §28.20.59:**

> **기준판이 축의 끝이었다.** 대원 넷이 `t=0` 에 동시에 치는 판이 **걸침이 통째로
> 겹치는 제일 나쁜 판**이었고, 표 여덟 개가 그 위에 서 있었다.
> 엇갈림 0.30초를 넣으니 **걸침 인원이 x1.23 → x1.99 로 살아나고**,
> 「3칸이 진다」·「넷이 셋보다 느리다」가 **사라졌다.**
>
> **대기 키는 팔 것이 없다.** 배율 x1.61 이 나오지만 좋은 쪽이 「어긋내기」고
> 그건 아무것도 안 눌러도 저절로 된다.

**열린 물음** (★ = 사람 답이 필요하다):
- ★ **전투 중 조작을 넣나** — 「모으기」로는 값이 없다. 값이 남은 것은
  **물러남**뿐이고 **대련장에 아직 없다** (§28.20.59)
- ★ **몸집 폭 `x0.95~1.10` 은 채택됐지만 뜻이 바뀌었다** — 살아 있는 경계 x0.941 을
  안 걸쳐서 **몸집이 결과에 아무 값도 안 한다(그림이다).** 그대로 두자는 것이 내 의견이고
  까닭은 §28.20.59 에. 화력 축으로 쓰려면 **하한을 x0.941 밑으로** 내려야 한다
- ★ **손잡이 넷 중 걸침 인원은 살아났다** (x1.99). 나머지 셋은 x1.31 · x1.04 · x1.03 —
  지우는 것은 사용자의 몫이다
- ★ 체이닝 조건 · 승리 조건 · 전진 뒤 남나 (§28.8 · §28.20.34/43)
- ★ 조장 중심 (§28.8.1 보류) · 자세 쌍을 누가 고르나 (§28.20.45)
- **무기 칸 수가 아직 단조롭지 않다** — 1칸 33초 · 2칸 44 · 3칸 53 · 4칸 33.
  **까닭은 안 쟀다**
- **앞 켜 96 · 켜 간격 15 를 누가 정하나** — **몸집 경계 x0.941 이 여기서 나온다**

**이동 레인과의 자리 (§28.20.60):**
- **32 대 32 는 안 나온다.** 우리는 3~4, 물량은 전부 적 쪽이다 (§28.6). 나오는 판은 **4 : N**
- 우리가 이동 레인에 필요한 수는 **문 앞에서 한 번에 몇이 우리에게 닿나**다.
  **한 칸 문은 켜당 인원을 1 로 만들어 상한을 6 → 2 로 조인다**
- **붙이는 시점은 이동 레인이 제안한다** (위층 `unit_field` 가 굳은 뒤).
  넘길 때 `approach_speed` 는 지워지고 앞 켜 거리 · 켜 간격도 같이 넘어간다

**함정 여섯:**
- **기준판도 재는 자가 고른 것이다.** `t=0` 동시 시작은 **제일 나쁜 판**이었다.
  새 표를 낼 때 **기준판이 축의 끝이 아닌지 물어라** (§28.20.59)
- **§28.20.36~53 의 표는 「적이 제자리에 서고 아무도 안 빠지는」 판에서 잰 것이다.**
  다시 재려면 `Fixtures.still()` 이나 `survey_crowd_limit.gd` 처럼 **스스로 꺼라**
- **다가옴과 빠짐은 따로 놓으면 아무 일도 안 한다.** 하나만 켠 판은 둘 다 끈 판과
  상한이 같다 (여섯) — **하나씩 재면 「효과 없음」으로 읽힌다** (§28.20.55)
- **판정 창과 체인 길이는 `tools/survey_clock.gd` 하나에 있다.** 창만 넓히면
  **체인이 먼저 떨어지고 그 판이 「무승부」로 찍힌다** (§28.20.57)
- **`--import` 0 에러가 정상을 뜻하지 않는다.** 화면은 `tools/check_backpack_screen.gd`
  로 따로 돌려라. 캡처만 GPU 를 쓴다 (§28.20.24 · §28.20.51)
- **조사 도구가 가끔 signal 11 로 죽고, 가끔 `Cannot convert argument 2 from int to int`
  같은 말이 안 되는 오류를 뱉는다.** 다시 돌리면 멀쩡하고 출력은 바이트 단위로 같다.
  RAM 은 20GB 가 비어 있었고 `gdformat` 도 한 번 같은 신호로 죽었다 — **우리 코드만의
  일이 아니다.** 죽으면 **표가 짧게 나오고 멀쩡해 보인다 — 줄 수를 세라**
