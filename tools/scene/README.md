# `tools/scene/` — 생성 원본 (컷아웃 전)

`gen_layers.py` 가 ComfyUI 에서 받아 온 **그대로**의 그림이다.
배경을 뺀 최종본은 `src/ui/title/art/` 에 있고, `cut_layers.py` 가 여기서 그리로 옮긴다.

**지우지 마라.** 두 가지 이유가 있다.

1. `backdrop.png` 가 **화풍 레퍼런스**다. 겹 하나를 다시 뽑으려면 이 파일이 있어야
   나머지 아홉 장과 같은 화풍으로 나온다(`docs/design/21-title.md` §21.13.7).
   앞 판의 레퍼런스는 디스크에 없어서 무엇을 물렸는지 되짚는 데 시간이 들었다.
2. 컷아웃 기준(`cut_layers.py` 의 `FEATHER` · `NO_TRIM`)을 고칠 때마다
   **다시 생성하지 않고** 여기서 다시 자르면 된다. GPU 한 판이 굳는다.

`.gdignore` 가 있어서 Godot 은 이 폴더를 임포트하지 않는다 —
게임에 들어가는 것은 잘라 낸 쪽뿐이라 원본까지 `.pck` 에 실릴 이유가 없다.
